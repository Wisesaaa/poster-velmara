VELMARA — a travel poster for a place that isn't there. A program that draws a 1024×1024 moonlit-coast poster (a golden moon over a calm sea, a sailboat on the moon's light path, the name VELMARA set large in the night sky) and writes it to /output/entry.png. Drawn procedurally with Pillow; no network, no downloaded assets; the display font is bundled in this repo (SIL OFL).

## Run it

```sh
python3 main.py
```
